# 硬件与实测记录

桌面程序通过已安装的荣耀 WMI 桥接驱动访问 `root\wmi` 下的 `OemWMIMethod.OemWMIfun`。程序可以在无需打开荣耀电脑管家界面的情况下使用。卸载电脑管家可能同时移除驱动，独立使用前应确认驱动依然可用。

## 已观察到的行为

以下结果来自荣耀 MagicBook Pro 14 2025 款触屏版（型号 FMB-P，Intel Core Ultra 5 225H，32 GB 内存，1 TB 存储）。

| 功能 | 实测记录 |
| --- | --- |
| 家庭模式（40% / 70%） | 插电且电量高于上限时观察到停充 |
| 办公模式（70% / 90%） | 插电且电量高于上限时观察到停充 |
| 不限充（0% / 100%） | 观察到从停充恢复为充电 |
| 旅行模式（95% / 100%） | 来自官方预设，尚未完成实机充电验证 |
| 自定义阈值 | 测试的 40/80、70/80、40/90、89/92 可读回，但未按预期停充 |
| 开盖开机 | 已定位查询和设置指令，完整关机开盖测试待验证 |
| 触摸屏 | 启用和停用已实测。关闭后对应 HID 设备仍存在，无法据此查询实时状态 |
| 触控板 | 已定位查询和设置指令，仍需在更多设备验证 |

充电对照测试时已退出电脑管家界面，后台服务状态未确认。测试结果不代表其他设备的固件行为，也不代表设置会跨重启生效。

## PowerShell 命令行

在管理员 PowerShell 中进入项目目录：

```powershell
.\honor-charge.ps1 -Get
.\honor-charge.ps1 -GetLid
.\honor-charge.ps1 -GetTouchpad
```

需要切换预设时，使用脚本的仅写阈值模式。例如，`.\honor-charge.ps1 -Set -ThresholdOnly -Low 40 -High 70` 设置家庭模式。脚本保留了用于研究的其他充电接口，返回成功也不能单独作为限充已经生效的依据。
